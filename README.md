# Wanderlust 

A full-stack Airbnb-inspired web application built using Node.js, Express.js, MongoDB, EJS, and Bootstrap.

## Features
- User Authentication
- Create, Edit & Delete Listings
- Reviews & Ratings
- Image Upload with Cloudinary
- Search Listings by Country

## Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- EJS
- Bootstrap
- Passport.js
- Cloudinary
